# Spec 004 - Experiment Evaluation

Essa especificação trata da funcionalidade de avaliação de um experimento. O sistema deve ser capaz de avaliar métricas acurácia, recall, precisão, falso positivo e falso negativo.

## Requisitos

### Requisitos Funcionais

 - RF-01 : O sistema deve ser capaz de gerar métricas de avaliação para cada experimento.
 - RF-02 : O sistema deve ser capaz de calcular acurácia do experimento
 - RF-03 : O sistema deve ser capaz de calcular precisão do experimento
 - RF-04 : O sistema deve ser capaz de calcular recall do experimento
 - RF-05 : O sistema deve ser capaz de calcular false aceptance rate do experimento
 - RF-06 : O sistema deve ser capaz de calcular false rejection rate do experimento

### Requisitos Não Funcionais

 - RNF-01 : As métricas devem ser mantidas em arquivo para consulta posterior.
